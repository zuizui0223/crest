## From four obligations to one ecological state

Keeping the four adequacy questions distinct does not mean that ecology must end with four different state variables. The opposite question is the one that motivates CREST: **if one ecological state is expected to support all four kinds of scientific work, what should that state be?** The answer is conditional rather than metaphysical. The four companion theories do not automatically inhabit one common state space, so CREST cannot identify one context-free partition that nature forces on every analysis. But when the relevant commitments are synchronized on one declared finite latent-world carrier, the joint state can be defined precisely.

Let \(U\) be a finite set of latent ecological worlds rich enough to carry the distinctions relevant to the declared future grammar, inherited semantic labels or history, retained response mechanisms, evidence relation, and report target. Let \(B\) be the baseline partition containing distinctions that the analysis is committed to preserving before the four adequacy conditions are imposed. On the partition lattice \(\Pi(U)\), represent the four requirements by refinement closures

\[
C_\Gamma,\qquad C_\mathcal H,\qquad C_\Theta,\qquad C_{D,T}.
\]

Their fixed points are state representations that satisfy, respectively, the future, inherited-semantic, mechanism-robustness, and target-resolution obligations on this common carrier. Under the finite closure conditions proved in CREST-J1, there is a unique coarsest common fixed point above the baseline:

\[
\boxed{
J=(C_\Gamma\vee C_\mathcal H\vee C_\Theta\vee C_{D,T})(B).
}
\]

This gives a direct answer to the representational question. For a configuration represented by world \(u\in U\), its CREST state is the equivalence class

\[
\boxed{
\operatorname{State}_{\mathcal C}(u)=[u]_J.
}
\]

Two configurations therefore count as the same CREST state when the least-information representation satisfying the declared scientific obligations is permitted to merge them. They count as different states when at least one obligation, possibly after interacting with refinements forced by another obligation, requires their distinction to be retained. The state is “minimal” only in this conditional sense: among representations adequate for this declared carrier and contract, no coarser partition can do all of the required work. CREST does not infer that the same partition is minimal under a different target, mechanism family, future repertoire, inherited meaning, or evidence contract.

This joint construction also corrects a tempting but inadequate procedure. One might independently compute the minimum state required by each audit and combine the four results once. CREST-J1 shows that this need not work. A distinction introduced by one audit can make another audit capable of detecting a further distinction, which can trigger another refinement in turn. The joint state is therefore obtained by fair repeated refinement to a common fixed point. Pairwise commutation of the audits is not required, and although the intermediate path can depend on audit order, the final least common fixed point does not.

A second qualification concerns existence. The four companion descriptions do not automatically share one coherent latent-world carrier. CREST-J3 and CREST-J6 therefore precede the joint-state theorem logically: under universal and controlled action contracts, respectively, they identify the greatest synchronized carrier compatible with the declared transition requirements. If the required carrier is empty or fails required coverage, the problem is not that the state partition is insufficiently fine. Rather, **there is no fully adequate joint state under that declared synchronization**. One must revise or repair the carrier contract before asking for the joint partition. CREST-J4 and J7 characterize two finite repair languages for this purpose.

A third qualification separates representational requirement from empirical identification. Let \(E_D\) be the reliability-qualified evidence partition: worlds in one evidence block remain observationally compatible under the declared experiment and reliability assumptions. CREST-J1 proves that a deterministic full joint-state report exists exactly when

\[
J\preceq E_D.
\]

If this relation fails, \(J\) still specifies the distinctions that an adequate state representation would have to preserve, but the available evidence does not identify which \(J\)-block is occupied. The appropriate report is then the set of joint-state blocks still compatible with the evidence. A requested ecological target may nevertheless remain reportable if that target is constant within each evidence block. Thus the theory distinguishes three questions that are easily conflated: **does a coherent carrier exist, what state resolution is scientifically required on that carrier, and has the evidence earned that resolution?**

This is the sense in which CREST seeks one ecological state without positing one intrinsic state ontology. The joint state is neither whichever coarse label happens to be convenient nor the maximally detailed microscopic description. It is the coarsest equivalence relation that survives the scientific work explicitly assigned to it, conditional on a declared carrier and contract. Contract-relativity therefore does not eliminate state identity; it specifies the domain within which state identity becomes a testable representational claim.
