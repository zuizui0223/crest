# Upstream provenance for the GLUE CREST reanalysis

Source repository: `James-S-Santangelo/glue_pc` (public GitHub repository accompanying Santangelo et al. 2022, *Science*).

Files used:

- `phenotypic-analyses/README.md` — confirms the pipeline cleans phenotype and environmental data, analyzes city clines, predicts clines from environmental data, and generates tables/figures.
- `phenotypic-analyses/analysis/tables/allCities_logisticReg_coefs.csv` — city-specific logistic-regression coefficients for standardized distance/urbanization metrics.
- `phenotypic-analyses/analysis/tables/eniroMeansSlopes.csv` — city-level environmental means and urban-rural slopes.
- `phenotypic-analyses/analysis/tables/elasticNet_coefSummary.csv` — predictor-selection frequency across 100 elastic-net fits.
- `phenotypic-analyses/analysis/tables/elasticNet_obs_result.csv` — repeated held-out prediction metrics.

Primary article DOI: `10.1126/science.abk0989`.

This CREST reanalysis does not redistribute the upstream dataset; it records derived interpretation and selected published/upstream table values with full provenance.
