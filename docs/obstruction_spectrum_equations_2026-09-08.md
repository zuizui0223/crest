# Obstruction-spectrum identities

For structural audit set N and coalition debt D(S):

1. D(empty)=0.
2. D({i}) is the standalone obstruction debt.
3. D(N)=D_joint.
4. Delta=D(N)-sum_i D({i}).
5. phi_i is the Shapley value of the cooperative game D(S).
6. sum_i phi_i=D_joint.
7. I_i=phi_i-D({i}).
8. sum_i I_i=Delta.

These identities make the numerical profile internally auditable: the axis-level attributions must close exactly to the pre-existing joint-debt accounting.
