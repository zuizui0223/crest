# CREST v0.7 positioning — from Möbius novelty to ecological interface identification

## Decision

CREST does **not** claim mathematical novelty for the Möbius transform of a unanimity-game component. In the explicit grammar family, once a decoder prerequisite set is fixed, the corresponding coalition term is a standard unanimity contribution and its Harsanyi/Möbius location is elementary.

The contribution claimed for v0.7 is instead the modeling correspondence:

\[
\boxed{
\text{minimal ecological interface prerequisites of a future decoder}
\longleftrightarrow
\text{interaction order of its state-addressability burden}
}
\]

The mathematics is accounting infrastructure. The scientific work is to identify the prerequisite structure from retrospective semantics, latent response structure, and the declared future target.

## Why companion semantics must be active

A CREST bridge is not considered semantically adequate merely because a history field and a mechanism field are non-integer objects.

For the retrospective side, raw routes must first be quotiented by equality of complete carried maps. Route coherence therefore changes the retained history interface.

For the latent-response side, primitive candidate laws must first be quotiented by equality of complete declared response tables. Candidate safety therefore changes the retained mechanism interface.

Future decoder access is then defined on these *derived semantic interfaces*, not on arbitrary route IDs or candidate IDs.

The canonical v0.7 regression uses three raw histories collapsing to two MLTR history modes and three candidate laws collapsing to two MRM response types. Decoder availability changes when either carried semantics or candidate-safe response type changes while raw axis cardinality is held fixed.

## Ecological identification rather than intrinsic interaction

CREST does not say that a shallow lake, pollination network, or other ecosystem intrinsically 'has' a particular interaction order. A declared target has a prerequisite set.

For target `T`, an interface is necessary if changing that interface while holding the other retained inputs fixed can change the correct target output. This counterfactual substitution rule identifies a minimal modeled prerequisite set `R_T`.

The shallow-lake worked case illustrates that one system can support multiple prerequisite structures depending on target:

- current-status report: no retrospective or latent-response prerequisite;
- legacy-sensitive recovery: history prerequisite;
- mechanism-specific intervention: latent-response prerequisite;
- composed restoration policy: both interfaces in the declared finite model.

Thus interaction order is target relative, not an intrinsic label attached to an ecosystem.

## Publication consequence

The submission manuscript should lead with:

1. state as information that must survive a temporal cut;
2. the strict realizability no-go for naive fixed-partition composition;
3. semantic derivation of retrospective and latent-response interfaces from MLTR/MRM primitives;
4. interface-prerequisite identification as the modeling contribution;
5. the Möbius order calculation as a consequence, not the novelty claim;
6. one ecology-grounded worked prerequisite audit.

The synthetic `m=10` 4-to-4096 table remains an illustration of one dependency architecture only.
