# Trajectory-first CREST program architecture — 2026-08-22

## Decision

CREST is no longer organized conceptually as "four audits combined into one higher theory." The direction is reversed.

The program now starts from a temporally extended ecological world and asks when that world can be compressed into a finite state for a declared scientific responsibility.

\[
\boxed{
\text{CREST: ecological state is a scientifically licensed compression of temporally extended ecological worlds.}
}
\]

The existing finite joint-state theorem remains valid and important, but it is now the finite construction layer below this world-level framing.

## Canonical hierarchy

```text
self-modifying ecological dynamics
        ↓
temporally extended possible worlds Ω
        ↓
observation / intervention context V
        ↓
snapshot sufficiency question
        ↓
structural reasons a snapshot merge can fail
    CCOC — future/composition
    MLTR — inherited semantics/history
    MRM  — retained mechanisms
        ↓
minimal adequate finite state J_{C,V}
        ↓
evidence licensing
    CED
        ↓
deterministic / set-valued / target-only report
```

## Why CED is not on the same ontic level

CCOC, MLTR, and MRM can each show that two worlds which look the same at the present snapshot should nevertheless be different required states.

CED asks a different question: after a state distinction is required, has the experiment or observation contract actually resolved it?

Therefore:

\[
\text{required distinction}
\xrightarrow{\text{CED}}
\text{licensed claim about that distinction}.
\]

CED remains part of the CREST program but is downstream of representational adequacy rather than a fourth source of underlying ecological difference.

## Snapshot sufficiency

Let \(X(\omega)\) be the present snapshot and \(q_{\mathcal C,V}(\omega)\) the required CREST state. Snapshot sufficiency means

\[
X(\omega)=X(\omega')
\Rightarrow
q_{\mathcal C,V}(\omega)=q_{\mathcal C,V}(\omega').
\]

The companion repositories provide distinct ways to construct or analyze violations of this implication.

## Companion ownership

### CCOC — future insufficiency

Owns exact closed-vs-open future-interface complexity, extension/compression lower bounds, and bounded-local sharpness witnesses.

CREST reading: a present merge can fail because a newly relevant future connection, interaction, or intervention exposes a hidden response distinction.

### MLTR — historical / semantic insufficiency

Owns inherited-law transport, least exact source-relative repair, transport defect, route coherence, and minimal history augmentation.

CREST reading: a present descriptor can fail because the meaning inherited from a source system or replacement history is no longer operationally coherent.

### MRM — mechanistic insufficiency

Owns candidate-safe response laws, minimal mechanism-safe quotients, ambiguity frontiers, and active mechanism discrimination.

CREST reading: a present merge can fail because retained mechanisms disagree on a future response that matters to the contract.

### CED — evidential licensing

Owns experiment-induced quotients, target-safe reporting, detection/failure architecture, calibration, and risk-limited reportability.

CREST reading: the required state may be finer than the state that current evidence can honestly identify.

## Finite theorem firewall

The trajectory-first framing does not by itself prove a new infinite, continuous, stochastic, or eco-evolutionary trajectory theorem.

Current proved CREST mathematics remains conditional on declared finite latent-world carriers and exact refinement/closure assumptions. The finite results establish:

- common-carrier feasibility under declared semantics;
- unique coarsest adequate finite state under the implemented closure assumptions;
- evidence licensing of that required state;
- action-expansion and monitoring-debt consequences;
- supporting lift/repair/noncommutation results.

The new architecture changes the **interpretive and logical order**, not the proof status of those results.

## Rule interpretation

A coarse ecological rule is treated as an effective law on a state quotient. If a wider future, different structural history, retained mechanism, or new scientific responsibility splits an old state fiber, the old rule need not have been false. It may have been valid only on the earlier quotient.

This motivates the program-level statement:

\[
\boxed{
\text{rule validity is conditional on the distinctions erased by the state remaining irrelevant.}
}
\]

## Stability interpretation

CREST distinguishes:

- dynamical stability of the ecological system;
- evolutionary stability under a declared evolutionary model;
- representational stability of the state quotient under changes in observation, intervention, mechanism, or reporting responsibility.

The existing finite action-expansion witness already shows that representational stability can fail before the ecosystem changes physically.

## Development routing rule

New work should be routed by question, not by superficial use of partitions or quotients.

1. Does opening the future require more state information? → CCOC.
2. Does structural replacement break inherited state meaning? → MLTR.
3. Do retained mechanisms disagree on required responses? → MRM.
4. Can the evidence identify/report the required distinction? → CED.
5. Does the work change the world-level definition, snapshot-sufficiency theory, quotient-law interpretation, or representational-stability theory across these layers? → CREST.

Do not add a new theorem family merely because a new ecological label can be attached to an existing refinement lemma.
