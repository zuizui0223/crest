# CREST sharp sequential state-debt law — 2026-09-06

> **Status:** candidate headline strengthening after the counterfactual response-capacity bound. The product/counting step is classical; the CREST contribution is the sharp connected realization that simultaneously fixes carrier gain, state debt, evidence debt, and target reportability.

## 1. Question

The capability–resolution theorem established

\[
\Delta |K^*|=1,
\qquad
\Delta K=m
\]

for arbitrary \(m\), and the response-capacity theorem then showed that the hidden resource is the distinguishing capacity of the future-response grammar.

The remaining question is more quantitative:

> **Along one sequential intervention channel, how much present-state information can H response-relevant stages create?**

The exact answer is a depth-times-response law.

---

## 2. Sequential response protocol

Fix one old state class \(C\). A newly relevant sequential intervention is applied for \(H\) stages. At stage \(h\), worlds in \(C\) can produce at most \(r_h\) distinguishable response symbols that are retained by the strengthened scientific responsibility.

Let the complete H-stage response record of world \(s\in C\) be

\[
\Sigma_H(s)=(Y_1(s),\ldots,Y_H(s)).
\]

The strengthened state may split \(C\) only according to distinctions contained in this response record.

## Theorem 1 — heterogeneous sequential state-debt bound

The old class \(C\) can split into at most

\[
\boxed{
\prod_{h=1}^{H}r_h
}
\]

strengthened classes. Hence the additional state information inside \(C\) is bounded by

\[
\boxed{
\Delta K_C
\le
\sum_{h=1}^{H}\log_2 r_h.
}
\]

### Proof

The strengthened classes inject into the realized sequential response vectors

\[
C\longrightarrow
R_1\times\cdots\times R_H,
\qquad
s\mapsto\Sigma_H(s),
\]

where \(|R_h|\le r_h\). The product space has at most \(\prod_h r_h\) elements. Taking \(\log_2\) gives the information bound. \(\square\)

This is the response-basis theorem specialized to an ordered intervention path, which gives it a direct temporal interpretation.

## 3. Constant response cardinality

If each stage has at most \(r\) distinguishable outcomes,

\[
\boxed{
|J_H^+|/|J_H^-|
\le r^H
}
\]

within one old state class, and

\[
\boxed{
\Delta K
\le H\log_2 r.
}
\]

This is the quantitative law that the earlier arbitrary-m construction did not make explicit.

### Binary corollary

For \(r=2\),

\[
\boxed{
|J_H^+|/|J_H^-|
\le 2^H,
\qquad
\Delta K\le H\text{ bits}.
}
\]

Thus one additional binary response-relevant stage can increase the maximum number of present state classes by a factor of two and can add at most one bit of required state information.

---

## 4. Inverse law — how much depth is necessary?

If a strengthened responsibility requires \(k\) additional bits and each sequential stage can expose at most \(r\) response types, then necessarily

\[
\boxed{
H
\ge
\left\lceil
\frac{k}{\log_2 r}
\right\rceil.
}
\]

Equivalently, if \(N\) strengthened state classes must be distinguished inside one old class,

\[
\boxed{
H\ge\lceil\log_r N\rceil.
}
\]

For binary responses,

\[
\boxed{H\ge k.}
\]

Large state debt therefore requires large sequential response capacity; it cannot be generated by a bounded-depth binary response path.

## 5. Sharp connected CREST family

The upper bound is attainable while preserving the defining CREST cross-gate conjunction.

Fix integers \(r\ge2\) and \(H\ge1\). Let

\[
X_{r,H}=\{0,1,\ldots,r-1\}^{H}.
\]

For every address

\[
x=(x_1,\ldots,x_H)\in X_{r,H},
\]

create a present world \(p_{x,0}\) and sequential worlds

\[
p_{x,1},\ldots,p_{x,H}.
\]

All present worlds \(p_{x,0}\) have the same output `neutral`. For \(h\ge1\), world \(p_{x,h}\) outputs

\[
\texttt{response-}x_h.
\]

Add two common worlds

\[
s=\texttt{safe},
\qquad
f=\texttt{fragile}.
\]

The old controllable repertoire is

\[
A^-_c=\{\texttt{hold}\},
\]

under which each path state and `safe` self-loop and `fragile` has no safe control.

The expanded repertoire is

\[
A^+_c=\{\texttt{hold},\texttt{probe}\},
\]

with

\[
p_{x,h}
\xrightarrow{\rm probe}
p_{x,h+1}
\qquad(0\le h<H),
\]

followed by

\[
p_{x,H}
\xrightarrow{\rm probe}f
\xrightarrow{\rm probe}s.
\]

The same newly admitted action therefore reveals the sequential response address and rescues the one previously nonviable world.

## 7. Exact state result

Let

\[
U_0=\{p_{x,0}:x\in X_{r,H}\}.
\]

Before `probe`, all worlds in \(U_0\) have identical output and identical `hold` futures, so

\[
\boxed{|J^-\restriction_{U_0}|=1.}
\]

After `probe`, the H-stage response record is exactly the address:

\[
\Sigma_H(p_{x,0})
=
(\texttt{response-}x_1,\ldots,\texttt{response-}x_H).
\]

Every one of the \(r^H\) address vectors is realized, and distinct addresses differ at some response stage. Therefore

\[
\boxed{|J^+\restriction_{U_0}|=r^H.}
\]

Consequently,

\[
\boxed{
\Delta K_{U_0}
=H\log_2 r.
}
\]

The sequential upper bound is therefore sharp.

Moreover, through partial horizon \(d\le H\), exactly the first \(d\) response coordinates have been exposed, so

\[
\boxed{
|J_d\restriction_{U_0}|=r^d,
\qquad
K_d(U_0)=d\log_2r.
}
\]

The information accumulation rate is constant until the full address is exhausted.

Thus the minimum additional evidence resolution needed for full-state identification is exactly

\[
\boxed{
D_E=H\log_2r.

A target constant on \(U_0\) remains reportable throughout.

## 9. Counterfactual information rate

For a sequential responsibility define

\[
\rho_{\rm CF}(H)
=
\frac{\Delta K_H}{H}.
\]

Then

\[
\boxed{
\rho_{\rm CF}(H)
\le
\frac1H\sum_{h=1}^{H}\log_2r_h.
}
\]

and in the homogeneous r-ary case

\[
\boxed{
\rho_{\rm CF}\le\log_2r
\quad\text{bits per response-relevant stage}.
}
\]

The sharp family attains equality at every prefix depth.

This quantity is not claimed as a universal empirical rate of ecosystems. It is a contract-relative finite information rate for how fast a declared sequential intervention can force refinement of the present state.

## 10. Ecological interpretation

The result changes the explanatory variable from the number of management actions to the temporal information content of their responses.

For a sequential intervention pathway with at most \(r\) distinguishable response types per relevant stage,

\[
\boxed{
\text{maximum added state knowledge}
=
H\log_2r
\text{ bits in the sharp case.}
}
\]

This yields a direct structural prediction:

> **Long ecological memory creates large management-induced state debt only insofar as successive stages expose additional response distinctions.**

A long delay with no new distinguishable response contributes no additional state information. Conversely, hysteresis, delayed loading, seed-bank legacies, successional bottlenecks, or sequential interaction rewiring can generate high debt when different latent worlds reveal distinct outcomes stage after stage.

The theorem therefore separates **calendar duration** from **response-relevant depth**. The relevant \(H\) counts distinguishable causal/management stages, not units of clock time.
