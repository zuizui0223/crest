# Shallow-lake restoration — worked identification of decoder prerequisites

## Status

Literature-grounded **model-identification example**, not an empirical estimate of a universal prerequisite set and not a new ecological causal claim.

This note reuses the already documented shallow-lake mapping in `shallow_lake_end_to_end_crest_case_2026-08-22.md`. Its purpose is narrower: show how CREST identifies the interface prerequisite set of a declared future decoder from the ecological meaning of the target, rather than assigning an interaction order first.

## 1. Primitive ecological interfaces

At one management cut, let the visible snapshot contain routine water-column status (for example a coarse turbid/eutrophic description).

The worked case already distinguishes two pre-state interfaces.

### History interface H

`H` records restoration-relevant nutrient history, especially whether prolonged external phosphorus loading has produced a sediment phosphorus legacy that remains relevant after external loading is reduced.

This is retrospective information. It is not inferred from the final CREST quotient.

### Latent-response interface Theta

`Theta` records the response-relevant mechanism class among alternatives such as:

- internal sediment-P persistence;
- fish-mediated trophic feedback;
- macrophyte-mediated clear-water feedback;
- mixtures when the declared candidate family includes them.

This is an MRM-style response classification: two mechanistic descriptions are equivalent only when the declared intervention responses are the same.

## 2. Prerequisite identification rule

For a declared future target `T`, call an interface `I` necessary when there exist two possible worlds that agree on all other retained inputs to `T` but differ on `I`, and the correct target output differs.

Formally, if `z` denotes all other retained inputs,

\[
I\text{ is necessary for }T
\iff
\exists i\neq i',z:\ T(i,z)\neq T(i',z).
\]

The minimal prerequisite set `R_T` is the set of interfaces that survive this counterfactual substitution audit. This is a modeling identification rule. It does not claim that field data automatically identify which world is realized.

## 3. Four restoration targets give different R

### Target A — current-status reporting

Question:

> Is the lake currently turbid/eutrophic under the declared water-column snapshot?

By construction this target is answered from the visible cut itself. Neither restoration history nor hidden response mechanism is needed.

\[
R_A=\varnothing.
\]

### Target B — history-sensitive recovery expectation

Question:

> After external-load reduction, is delayed recovery still expected because of legacy phosphorus accumulated under the previous loading history?

The existing shallow-lake mapping explicitly treats prolonged past loading and accumulated sediment phosphorus as a source of delayed recovery after external loading is reduced. Holding the declared response channel fixed, changing whether that legacy exists can change this target.

Thus history is a prerequisite for this target:

\[
R_B\supseteq\{H\}.
\]

This worked example does not require mechanism identity beyond the sediment-legacy response channel already fixed by the question, so its minimal modeled prerequisite is

\[
R_B=\{H\}.
\]

### Target C — mechanism-specific supplementary intervention

Question:

> Conditional on a fixed relevant restoration history, which supplementary intervention channel should be tested: sediment-P control or food-web/macrophyte intervention?

The existing mapping states that internal-P persistence and biological feedback need not respond to the same interventions. Holding the relevant history fixed, changing the latent response type can therefore change the intervention target.

\[
R_C=\{\Theta\}.
\]

### Target D — composed restoration policy

Question:

> Given the lake's restoration-relevant loading history and its retained response type, which intervention sequence is licensed after external-load reduction?

This target is deliberately composed from the two previous questions: it conditions policy both on whether a legacy generated by past loading remains relevant and on which response mechanism is retained. Under this declared target, substituting the history interface at fixed response type can change the licensed sequence, and substituting the response type at fixed history can also change it.

The worked model therefore identifies

\[
\boxed{R_D=\{H,\Theta\}.}
\]

This is a **target-relative model identification**, not an assertion that every shallow-lake restoration problem has the same prerequisite set.

## 4. Why this matters for CREST

The same ecological system can induce different interaction orders because different scientific targets ask different questions of the same temporal cut.

| declared target | identified prerequisite set |
|---|---|
| current-status report | `empty` |
| legacy-sensitive recovery | `{H}` |
| mechanism-specific intervention | `{Theta}` |
| composed restoration policy | `{H, Theta}` |

Combined with the explicit-grammar characterization, these correspond respectively to a future main effect, history × future interaction, mechanism × future interaction, and a three-way history × mechanism × future contribution for any exterior information made addressable by that decoder.

The ecological contribution is therefore not that shallow lakes 'have three-way interaction' intrinsically. It is that **the interaction order of the state burden is identified from the dependency structure of the declared restoration target.**

## 5. Claim firewall

This note does not claim:

- empirical estimation of `R_T` from a fitted shallow-lake dataset;
- that sediment legacy and biological feedback are statistically independent;
- that the four targets exhaust restoration decisions;
- that `R_D={H,Theta}` is universal across lakes;
- that the literature establishes the numerical bit depth used in synthetic CREST benchmarks.

The source literature and the earlier CREST case support the ecological ingredients: nutrient-loading legacy, sediment-P persistence, fish/macrophyte feedback, and intervention-specific responses. The prerequisite sets above are then identified **within the explicitly declared finite decision model** by counterfactual substitution.
